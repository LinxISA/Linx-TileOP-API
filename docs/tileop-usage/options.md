# `fixp::Options` 使用指南

`fixp::Options` 是矩阵类 TileOP 的显式属性载体。带 `options` 的重载不是基础
重载的重复写法：只有当 kernel 需要修改默认后处理行为时才选择它。

## 何时使用

| 需求 | 选择 |
| --- | --- |
| 普通矩阵计算，接受操作默认属性 | 调用不带 `options` 的基础重载。 |
| 量化、激活、转置、scale 或辅助统计输出 | 调用带 `const Options &options` 的重载。 |
| 只想“显式传零”获得默认行为 | 不要传 `options`；零值并不自动等同于属性未启用。 |

## 配置原则

1. 先选择具体操作页；每个操作只支持 `Options` 属性的一个子集。
2. 仅启用该操作确实需要的属性。未启用的可选 Tile/标量描述符必须保持为空。
3. 启用量化、PReLU、RowMax、GroupMax、MaxAbs 或 CScale 等模式时，提供该模式要求的
   对应操作数，并确保其 dtype、shape、layout 与主矩阵相容。
4. 转置属性只对页面明确支持的矩阵主输入有效；不要把它当作任意 Tile 的通用 layout 转换。

## 开发前检查表

| 检查项 | 要确认的内容 |
| --- | --- |
| 操作支持性 | 当前 `TMATMUL*` 或 `TGEMV*` 页面明确支持所需属性。 |
| A/B/C/D 类型 | 主输入、累加器和输出的数值类满足该重载。 |
| 可选操作数 | 每个已启用属性都提供所需 Tile 或标量，未启用属性不提供伪占位值。 |
| shape / layout | scale、bias 与辅助输出的 shape、CUBE layout 和 location 相容。 |
| 默认行为 | 不传 `options` 与传入一个“空/零” options 不是同一接口契约。 |

## 排障

当带 `options` 的调用失败时，先将调用缩减为基础重载，再逐一启用属性。每次只增加
一个属性及其所需操作数，并检查生成汇编中的 `B.FPATR`、相关 binder 和输出 binder。
这能区分“主矩阵类型/layout 不合法”和“某个 options 组合不合法”。

具体字段、builder 和枚举值以对应 API header 与该操作页的约束、默认值和参数说明为准；
本页只说明接口选择与组合原则，不定义未在当前操作页公开的属性。
